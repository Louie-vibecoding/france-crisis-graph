# 法国危机关系图谱

仿 Obsidian 图谱视图的交互关系图：法国财政与福利、移民、中东战争与 2026 年秋季运动之间的因果关联。

在线访问：https://louie-vibecoding.github.io/france-crisis-graph/

## 文件

| 文件 | 作用 |
| --- | --- |
| `data.js` | **全部内容都在这里**：节点、关联、说明文字、关键数据、来源。改内容只需要改它。 |
| `index.html` | 页面的样式和交互逻辑，一般不用动。 |
| `d3.min.js` | 图形库（d3 v7.8.5），放在本地，不依赖外部网络，大陆也能打开。 |

## 怎么改

1. 用任意文本编辑器（VS Code、记事本都行）打开 `data.js`。
2. 按文件开头的注释改：
   - 加一个节点：在 `nodes` 里照格式复制一行，换一个新的 `id`。
   - 加一条关联：在 `links` 里加 `{ source: "起点id", target: "终点id", strength: "strong", note: "说明" }`。
   - `strength` 只能填 `strong`（较直接）、`weak`（间接）、`contested`（有争议）。
3. 保存后双击 `index.html` 就能在本地预览；推送到 GitHub 后在线版本会在一两分钟内更新。

注意：每一项之间要有英文逗号，文字要用英文双引号括起来。改完页面空白，多半是少了逗号或引号。
